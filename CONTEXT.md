# German Wordle

A daily word-guessing game in German: every player gets the same five-letter word each day and has six tries to find it.

## Language

**Game**:
One player's attempt at one day's Solution: up to six Guesses, ending won or lost.
_Avoid_: Round, session, match

**Solution**:
The five-letter word all players must find on a given day.
_Avoid_: Answer, word of the day, target

**Guess**:
A five-letter word from the accepted word lists that a player has submitted in a Game.
_Avoid_: Attempt, try, challenge

**Current row**:
The Guess a player is still typing and has not yet submitted.
_Avoid_: Current guess, input

**Result**:
The outcome of a finished Game: its day, its Guesses, and whether it was won.
_Avoid_: Score, outcome, submission

**Leaderboard**:
The optional shared ranking of players' Results, per day and overall.
_Avoid_: Ranking, scoreboard, highscores

**Identity**:
The name and shared passphrase under which a player takes part in the Leaderboard.
_Avoid_: Account, user, login

**Standings**:
The ranked list the Leaderboard shows for one day or overall.
_Avoid_: Entries, table, rankings

**Hard mode**:
A player setting under which every Guess must reuse the hints revealed by the previous Guess; it can only be switched on before the first Guess of a Game.
_Avoid_: Strict mode, game mode
